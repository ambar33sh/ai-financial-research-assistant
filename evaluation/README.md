# Evaluation

The project will use a curated benchmark of 50–100 questions over the sample financial reports.

## Categories

- Factual document QA
- Numerical QA
- Comparative QA
- Risk analysis
- Summarization
- Citation verification

## Metrics

- Recall@K for retrieval
- Citation correctness
- Answer relevance
- Faithfulness to retrieved evidence
- Average latency
- Token usage/cost when an API LLM is configured

Results must be generated from actual runs. No performance numbers are claimed until the benchmark has been executed.
